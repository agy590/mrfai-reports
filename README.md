# MrFai Reports

A small public GitHub Pages site for **future** reports that are explicitly allowed for public sharing:

- `tech` — daily technology news
- `content` — MrFai Agent notes
- `market` — daily market briefings

It intentionally excludes MGC trading analysis, health checks, AI Radar, cleanup reviews, local-state snapshots, inputs, credentials, and all historical report backfills.

The publication boundary is enforced by a local allowlisted publisher. GitHub Pages publishes `main/docs`.
