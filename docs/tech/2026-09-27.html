⭐ 高热 AI / 生命科学 🟢 多方确认

核心事实：Anthropic 内部新成立的分子生物学团队给出"在 19 亿蛋白簇中找新的反转录酶系统"的研究 brief，由 Claude Mythos 5 跑的 agent 完成。一个 agent 规划与执行，一个 agent 复核，全过程 21.5 小时无人干预，949 个 session、2.156 亿 token。最终挑出 ART（array-associated reverse transcriptases）：酶本身此前文献已存在，但 Claude 是第一个发现旁边那串"CRISPR 状"DNA 重复序列与配对基因的。重复 3-21 次，cas 基因缺位。Anthropic 跑了 10 次复现都没重现原结果——说明 agent 行为本身有随机性。
