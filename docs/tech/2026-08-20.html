1. Stripe 收购 OpenRouter：AI 模型路由被支付巨头拿下

AI / 创业并购 ⭐ 高热 🟡 单源但权威

核心事实：Stripe 收购 AI 网关 OpenRouter。OpenRouter 充当开发者集中式 API 层，让一个 key 路由到 OpenAI / Anthropic / Google 等多家模型；Stripe 把 AI 用量与计费中介纳入金融基础设施。

为什么重要：标志 dev-side LLM 中间层价值被主流金融基础设施认可。下一步被吞并的可能是 observability / eval（LangSmith 类）。
