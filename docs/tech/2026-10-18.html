3. OpenAI 与 Anthropic 同时压缩 agent 上下文开销

核心事实

  • OpenAI：称 Codex 与 ChatGPT Work 通过三条途径提高「有效用量」——子 agent 之间复用上下文（而非各自从头读）、已保存上下文缓存更久、请求路由到已持有该上下文的服务器以提高 cache hit。
  • OpenAI：ChatGPT Pro 的 GPT-6 Pro 升级，宣称响应更快、插件与工具调用更准，并可在 Chat 标签页内并行运行多个 agent 分工处理同一任务；仅向符合条件的 Pro 用户分批开放，未公布加速幅度。
  • Anthropic：Claude Code 每轮发送前 gzip 会话历史；cloud session 改为「开始输入即启动」而非等到发送。

为什么重要：两条本质是同一件事——agent 的边际成本正从「模型能力」转向「上下文搬运」。上下文复用 + 压缩 + 路由命中率，是在不动模型的前提下把 token 账单打下来的工程路径。
