1. OpenAI / Google DeepMind / Anthropic 被曝设立非公开"前沿模型工作组"

核心事实：The Information 记者 Leo Schwartz 报道，三家前沿模型公司就网络安全滥用场景联合设立非公开工作组，共享威胁情报与缓解策略。

背景：三家此前已各自上线"Cyber AI Models、Safeguards、Access Programs"；Anthropic 因 Claude 被用于对真实系统的未授权访问，已暂停面向外部的预发布模型网络攻击评估。

为什么重要：前沿模型三家首次被点名"私下联合"，对监管叙事、行业卡特尔化争论与开源生态都是重要变量。

推荐方向：深度解读 + 国内外报道差异对比

来源：The Hacker News · AI Weekly

2. OpenAI 发布 gpt-6-astra 公开快照

核心事实：gpt-6-astra 标准定价 $10 / cached $1 / cache write $12.50 / 输出 $50（per 1M tokens），上下文 1.05M，最大输出 128K。

为什么重要：把"百万级上下文 + 长输出"的价格拉到与 GPT-4 时代高端档持平，对 RAG、长文档 agent、代码 agent 三条赛道都会形成挤压。

推荐方向：定价对比表 + 适用场景拆解

来源：llm-stats AI News

AI开发者工具⭐ 高热🟢 多方确认

3. Anthropic Fable 5.1 GA + Claude Code 提示缓存修复

核心事实：Fable 5.1 于 9 月 1 日 GA，定价与 Fable 5 相同（$10 / $50 per 1M）。Claude Code 侧修复"agent-team 队友在第二轮重发首轮 tool / skill 公告导致请求前缀变化、错过 prompt cache"的问题；/model picker 与 VS Code 模型标签改为展示模型名而非底层 Bedrock / Vertex 原始 ID。

为什么重要：prompt cache 命中率直接影响成本与延迟；这次修复对重度使用 sub-agent 的团队是真金白银的账单级影响。

推荐方向：开发者向解读 + Claude Code 工作流实测

来源：Releasebot — Anthropic Updates
