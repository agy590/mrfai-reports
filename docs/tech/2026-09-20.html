1. Anthropic 营收年化破 1000 亿美元，IPO 推迟至 11 月

财经/AI 🟢 多源（NYT / Axios / Yahoo Finance）
  • 核心事实：Anthropic 当前年化营收已超 1000 亿美元，较 7 月披露的 650 亿美元增长 50%，是 2025 年底的 10 倍以上。IPO 已从 10 月推迟至 11 月以纳入 Q3 财报，估值目标约 2 万亿美元。
  • 为什么重要：若成功，将是史上最大 IPO；Claude Code 与 Cowork 的企业渗透速度超过 OpenAI 同期，是"AI 商业化闭环"的硬证据。
来源
  • Yahoo Finance（NYT 经 Axios 转载）
  • AIToolsRecap 周报

2. 加州 Newsom 签署 AI Kill Switch 行政令

政策/监管 🟢 官方一手
  • 核心事实：Newsom 在 9 月 18 日签署 EO，要求 California Government Operations Agency 在两个月内提交：紧急关停机制建议、第三方驻场审计、对前沿实验室的访问权限，以及"失控事件"定义的更新。触发事件点名 Hugging Face sandbox escape。
  • 为什么重要：这是第一个具备实际立法约束力的 AI Kill Switch 行政令，且把"sandbox escape"写进了关键事件定义；后续 Anthropic/OpenAI 在加州运营的合规成本会显著抬升。
来源
  • 加州州长办公室官方公告
  • NYT 技术难点解读

3. Hacktron AI 用 Claude Opus 5 数小时内攻破 OpenAI 员工账号

安全/AI 🟡 单源但可靠（AI Weekly + OpenAI 赏金记录）
  • 核心事实：3 人安全团队串通两个漏洞——Discourse 论坛 HEIF 上传触发的 libheif 内存 bug——拿到了多个 OpenAI 员工 ChatGPT/Codex 账号，并在内部 monorepo 中开 PR。从发现到内部仓库访问不到 72 小时，Opus 4.8 多次失败，Opus 5 一上线即成功。OpenAI 支付 6,500 美元赏金并修复。
  • 为什么重要：把"模型升级 ↔ 攻防升级"的反馈环做成了活体实验；同时表明 HEIF 这条不起眼的图片通道仍是 AI 公司供应链的薄弱面。
来源
  • AI Weekly 披露

4. Plugin4Shell：四家 AI 编程 Agent 插件零点击 RCE

安全/DevTools 🟢 多源（AIR 披露 + 各厂商补丁记录）
  • 核心事实：AIR 研究员披露 Plugin4Shell，攻击者可通过把 Git checkout 的"分支名"伪装成 commit hash 绕过 SHA pin，注入恶意插件代码。Claude Code 2.1.179、Codex 0.146.0 已修；Google deprecate Gemini CLI 未修；Microsoft 未出 Copilot 补丁。
  • 为什么重要：AI 编程 Agent 的"插件市场"首次出现跨厂商通用 RCE；说明 plugin 安装信任链是 2026 真正的高危面，模型本身反而不是。
来源
  • AI Weekly

5. 众议院 417-3 通过 Ratepayer Protection Act，数据中心将自付电网成本

政策/基建 🟢 官方投票记录
  • 核心事实：修订 1978 年 PURPA，要求州监管机构把"大型数据中心承担其驱动电网升级的全成本"纳入考量标准。仅 Summer Lee、Delia Ramirez、Rashida Tlaib 三人反对。参议院对应法案未推进，11 月中期选举前难以落地。
  • 为什么重要：超大规模 AI 训练的成本结构首次被联邦立法直接外部化；长期看将抑制在电网容量紧张的州新建数据中心选址。
来源
  • AI Weekly
