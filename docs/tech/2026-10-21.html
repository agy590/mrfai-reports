1 · ChatGPT 推出 Locked Chats，敏感对话可用 PIN / 生物识别上锁

2026-10-20 科技 / AI 产品 🟢 多方确认 VERIFIED

核心事实

OpenAI 开始向 ChatGPT 推送 Locked Chats（锁定对话）。被锁定的对话会从常规聊天历史、置顶对话和对话搜索中移出，进入侧边栏 Projects > Locked chats；Web 与桌面端需输入 4 位账号 PIN 解锁，移动端还可用 Face ID / Touch ID 或设备解锁。

官方帮助中心同时写明了几条边界：锁定不构成端到端加密或独立加密保险库，不改变数据保留时长，不改变"Improve the model for everyone"设置；启用 Memory 时 Locked Chats 拥有独立记忆区，锁定后新增消息只更新该区记忆、不回流到普通 Memory。重置 PIN 将永久删除全部被锁对话与文件，且不可恢复。功能不适用于临时对话、群聊、共享链接会话、Codex 对话与 ChatGPT for Healthcare；覆盖 Free、Go、Plus、Pro、Business、Enterprise、Edu 计划，逐步推送。

为什么重要

这是消费级 AI 产品的隐私设计第一次正面回应"设备被人拿到 / 屏幕被人看到"这个高频场景，形态上明显对标 WhatsApp 的 Chat Lock。但必须把话说准：它解决的是社交场合的窥屏，不是数据存储安全。OpenAI 自己把"不是端到端加密""重置即删除"写进文档，说明这是访问控制层方案，不是密码学方案。对企业采购者而言，Locked Chats 不改变数据驻留、合规审计与保留策略，不能当作合规结论使用。

2 · DeepSeek 全面开源内部推理框架 DeepInfer（Apache 2.0）

2026-10-20 ~ 10-21 科技 / 开源 🟡 多家一致报道，未取原始仓库 PARTIAL

核心事实

DeepSeek 宣布将内部推理框架 DeepInfer 全面开源，协议为 Apache 2.0。该框架基于 vLLM，为 V4.1-Flash 模型提供快速、可扩展的推理服务；同步开源 deepseek-recipe，用于复现官方 API 的 token 处理流程。公司给出的动机是降低算力成本与能耗，多篇报道同时提到其对外称该栈可支撑极高的吞吐与毛利水平。

为什么重要

开源推理栈和发布新模型是两条不同的曲线：后者拼能力上限，前者拼单位 token 成本。DeepSeek 把自家生产环境的推理栈整个放出来（而非只放权重），等于把"别人能抄的成本结构"变成行业基线——对下游开发者是直接降本，对美欧厂商是价格战压力。注意：本次未取到 DeepSeek 官方仓库或博客原文，协议与"基于 vLLM"等细节来自多家转述，以官方仓库为准。

3 · Anthropic / Google / OpenAI 三家新模型同时进入"被提前曝光"阶段（均未官宣）

2026-10-19 ~ 10-20 科技 / 模型 🟡 转述 The Information，厂商未确认 PARTIAL

核心事实

The Information 于 10 月 19 日报道了三条尚未发布的后续模型线索，多家媒体在 10 月 19–20 日跟进转述：

  • Anthropic：在训一个更擅长"推断用户真实意图"的模型——早期测试者称其能从模糊指令里反推根因（例如修 bug 时会追问是否要一并修复相关问题）并给出非常规解法；尚不确定归属 Fable 线还是 Opus 线。

报道方同时提示，部分时间表可能滑到 11 月；三家均未正式发布。

为什么重要

三家的方向已经一致：竞争焦点从"通用智能分数"转向单位成本、意图理解与视觉任务。但这条信息目前属于"路线图泄露"而非"发布"，节奏上很容易被误读为已发布——这正是它值得单独成条的原因：内容侧如果引用，必须标注"报道 / 未官宣"，否则等于替厂商官宣。

4 · Anthropic IPO 前夜：十年算力承诺超 6000 亿美元；OpenAI 据报抢跑融资 300 亿美元

2026-10-20 ~ 10-21 财经 / 算力 🟡 转述 WSJ / 路透，未取原文 PARTIAL

核心事实

据《华尔街日报》援引 Anthropic IPO 招股书草稿：该公司未来十年算力相关承诺支出合计逾 5180 亿美元，总算力承诺支出将超过 6000 亿美元，计划总开支最高或达 7500 亿美元。同期披露口径为 2026 上半年营收 163 亿美元、算力支出约 90 亿美元、净亏损超 807 亿美元（其中 720 亿美元为可转换票据等融资工具估值变动带来的会计计提）。公司寻求以 1.5 万亿–2 万亿美元估值于 11 月上市，部分投资者对营收表现失望，预期估值可能落到 1.5 万亿美元以下。

另据路透报道，OpenAI 正赶在 Anthropic 上市前洽谈约 300 亿美元融资，估值超 1.4 万亿美元。

为什么重要

这两条是同一件事的两面：把算力从"自建数据中心"变成"长约承诺"之后，头部 AI 公司的财务报表第一次出现十年量级的刚性支出。这会同时改变两件事——一是下游推理服务的价格底部被压得更低（长约锁量换来更低的单位成本），二是 AI 资本开支的信用风险开始进入公开市场定价视野（见速览中的 CDS 交易量）。此外，"上市窗口"本身成了竞争变量：OpenAI 选择在 Anthropic 上市前抢先完成融资，说明资本市场对 AI 叙事的窗口期在收窄。

今日观察

1 · 今天的新闻密度不在"发布了什么"，而在"成本曲线分成两条"

一边是 DeepSeek 把生产级推理栈开源（单位成本往下），一边是 Anthropic 签下超 6000 亿美元的十年算力承诺（总量往上）。这两件事同时发生并不矛盾：长约锁量能换来更低的单位成本，于是头部厂商有动机签更大的长约，同时把效率工具开源以维持开发者生态的黏性。判断 AI 应用层机会时，看的应该是"单位 token 价格曲线"，而不是模型榜单。

2 · 报道时间与发布时间正在分离，这是一个新的内容风险点

The Information 提前放出三家路线图、厂商却还没官宣，意味着"AI 圈今天发布了什么"这个命题本身开始不稳定。内容侧最常见的错误会从"传谣"变成"抢发未发布"。可执行的做法很简单：把每条 AI 新闻标注为三档——已发布 / 官方预热 / 媒体爆料，并把日期写成"报道日"而不是"发布日"。

3 · 隐私功能是访问控制，不是加密

Locked Chats 解决了真实的痛点（掏手机给别人看、地铁上被瞥见），但官方文档白纸黑字写着不是端到端加密、不改变保留期、不改变训练设置，且重置 PIN 会连内容一起永久删除。传播时把它写成"ChatGPT 加密了"，是这条新闻最可能被消费错的方式。

4 · 值得留意的资金结构信号

AI 名字的信用违约互换（CDS）9 月周均交易量放大 4.5 倍以上。这不是危机信号，但它说明市场第一次开始为"AI 资本开支能不能兑现"定价——也就是说，AI 基础设施从科技叙事进入金融风险管理叙事的阶段了。
