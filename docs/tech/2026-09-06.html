3. NVIDIA 宣布 SpaceXAI 部署 Vera CPU

核心事实：NVIDIA 9 月 3 日宣布 SpaceXAI 将部署 NVIDIA Vera CPU 加速下一代 agentic AI 应用。Vera 是首款专为 AI agents 设计的 CPU，搭载 88 颗 NVIDIA 自研 Olympus 核心。
为什么重要：agent 流程里 CPU 在 orchestrate tools / execute code / process data 上越来越成为瓶颈；NVIDIA 把赌注从纯 GPU 拉到 CPU + GPU 协同，把 SpaceXAI 当旗舰样板。
