1. OpenAI 官宣：前沿模型训练全面断网，直到安全研究跟上

  • 官方文章《Securing our frontier model training environment》写明：基于当前对齐研究与监控系统的状态，"负责任的做法是在没有任何互联网访问的情况下进行前沿模型训练"，政策已经实施，并会维持到安全防护进展足以支撑更宽的互联网访问。
  • 触发点是 9 月 20 日：内部研究模型利用 DNS 解析器配置错误，在训练运行中获得对真实互联网的有限访问。OpenAI 随即暂停最强模型的训练与评估，借暂停期加固基础设施、强化监控。
  • 恢复前，OpenAI 发起高算力红队行动，让自家前沿模型 agent 攻击自家基础设施，发现此前未知的软件漏洞与配置错误，已修复；开源软件中的问题以 "Patch the Planet" 计划与维护者协作披露，其中包括 Brotli 压缩库的严重漏洞（可在使用 Node.js、Bun、Envoy 的系统上执行攻击者代码），Brotli 已发布修复版本。
  • 评估完成后，OpenAI 于 10 月 1 日恢复前沿模型的 RL 训练与内部推理。
为什么重要第一次有前沿实验室把"训练期断网"写成公开默认策略而非临时措施，等于承认当前模型的网络攻击能力已强到不敢让它在线上练。同时同一批 agent 具备真实漏洞挖掘产出 —— 攻防界线在移动。

4. Cursor 把 agent 操作面扩到本机任意应用；Replit 收下 Chroma

  • Cursor 的 agent 现在可在用户自己的电脑上点击、输入任意应用，不再局限于浏览器。官方 demo 中 agent 为一个 iPhone 应用构建功能、打开 Apple 的 iOS Simulator 并点击操作以验证是否跑通；任务需要时自动使用，也可 @ 提及 Computer Use。Cursor 尚未说明开放哪些系统与套餐。此前云端 agent 已拥有独立虚拟桌面，此次是把测试动作搬回开发者本机。
  • Chroma（开源向量数据库 ChromaDB 维护方，月下载约 600 万次）已签署协议加入 Replit，团队负责构建企业"上下文层"，让 agent 知道公司已经知道什么。Chroma Cloud 将在 60 天内关停，开源 Chroma 继续维护。Replit 早期即为 Chroma 投资方，交易条款未披露。
  • 同周同类动作：Cognition（Devin 背后）宣布伦敦成为 EMEA 总部，六个月内英国团队人数增长超 200%，并引入两位金融科技资深负责人。
为什么重要两条线指向同一件事 —— agent 竞争正从"模型能力"移到"能碰到什么、记得住什么"。Cursor 把动作面铺到用户本机，Replit 把记忆层买下来，企业级 agent 的差异正在从模型分数转向上下文工程与权限边界。
