4. Nvidia 发布开放权重语音转写模型 Nemotron 3.5 Transcribe

类型科技 / 语音 AI　热度⭐ 高热　时效📰 2026-10-28　可信度🟢 已核验原文
核心事实Nvidia 发布免费开放权重的 Nemotron 3.5 Transcribe 语音转写模型，并同步发布第 2 版开源语音数据集 Granary，可配合 NeMo Speech 定制行业术语识别。
关键数据30B 参数；最多 40 种语言转写、31 种语言与英语互译；最长 1 小时录音；最多区分 8 位说话人；官方称在 Hugging Face Open ASR Leaderboard 等基准上领先；单芯片可运行——覆盖 Jetson AGX Thor、DGX Spark 与 Blackwell 数据中心芯片；限制：只处理录音，不支持直播流；同系列更小模型为 Parakeet（1.1B 参数）。
各方反应官方把场景指向会议记录与医疗转写这两类已落地的企业级场景，并强调可用数据集与 NeMo 定制成垂直行业术语；同期赛道拥挤——Mistral 本月发布 Voxtral 3，ElevenLabs 推出 Realtime，Salesforce 发布 Launa-Omni。
影响语音模型正从"闭源 API 竞争"转向"可本地部署 + 可定制 + 单芯片跑"的硬件绑定路线，Nvidia 用开放权重把 Jetson / Blackwell 的价值主张往前推了一层；"不支持直播"也说明实时语音仍被闭源方案占着。
