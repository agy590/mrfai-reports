4. Cohere 发布 Embed 5（Pro / Fast 双 tier），共享 embedding 空间

⭐ 高热 📰 2026-10-01（厂商公告 9-30） 🟢 多方确认 科技 / AI / 企业
核心事实Cohere 发布 Embed 5 系列，包含 Pro（最高质量）和 Fast（低延迟、低成本）两个 tier；两者共享同一 embedding 空间，可用 Pro 建索引、Fast 直接查询而无需重建；GA 上线于 Cohere API、Model Vault、Microsoft Foundry、Amazon SageMaker。
关键数据128K token 上下文窗口；支持 100+ 语言；多模态（text / image / fused）；Pro 定价 $0.12 / 1M token（text）、$0.40 / 1M token（image）；Fast 定价 $0.08 / 1M token（text）、$0.40 / 1M token（image）；解析文档 suite 平均分 84.8（Pro）vs Voyage 4 Large 83.6、Embed 5 Fast 83.4、Gemini Embedding 2 80.8、Embed 4 78.6。
背景Cohere 是企业 embedding 模型老玩家；Embedding 4 是上一代；同期竞品有 Voyage 4 Large / Nano、Gemini Embedding 2、Jina Embeddings v5 等。
各方反应
  • 官方博客：主推"index with Pro, query with Fast"模式，声明跨 tier 查询仅带来 1.6%–2.7% 平均得分损失。
  • MediaRelease.co / HPCwire / Data Phoenix：跟进 GA 状态与定价结构。
  • 行业评论：默认部署建议从"全 Pro"切到"Pro 索引 + Fast 查询"，单次检索成本下降约三分之一。
影响分析短期——RAG / Agent 检索路径成本结构被重写；中期——私有 vLLM 部署成为受监管行业的默认入口；远期——embedding 空间共享可能成多 tier 模型的标准做法。
