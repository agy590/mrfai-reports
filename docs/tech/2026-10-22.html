1. AI 挖出 PHP 双重致命漏洞，NSA 发警报，全球 70% 网站受影响

两个自 PHP 5（2004 年发布）起就存在的严重漏洞被披露，PHP 基金会已发布补丁，美国 NSA 发出警告——若站点无法立即修补，NSA 建议将站点下线直至可修复。漏洞可导致攻击者侵入服务器文件系统或 Web 应用所用的数据库。

  • PHP 支撑约 70% 的网站（有统计称超 3300 万个站点）
  • PHP 8.1 及更早版本已停止支持；官方建议升级到 PHP 8.5.12
  • 漏洞存在时间跨度：自 2004 年的 PHP 5 起

安全测试公司 Calif 参与 OpenAI 的 "Patch the Planet" 开源漏洞计划，用 GPT‑5.6 Sol 找到其中一个漏洞；Google 的 Wiz 团队则用自家安全 agent Wiz Atlas，配合 Gemini 4 Argon 与 GPT‑5.6 Sol，找到多个 PHP 漏洞。两方均按负责任披露流程与 PHP 官方合作修补后再公开。

这是"AI 用于防御"第一次给出可量化、跨厂商、可复现的规模证据——不是演示，是覆盖全球 70% 网站的存量代码。同时它把开源维护的负担问题重新推上台面：漏洞被发现的速度，已经超过很多站点的打补丁能力。
