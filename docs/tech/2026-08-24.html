2. Anthropic Claude Developer Platform Python SDK v1.0 发布

⭐ 高热 🟡 单源但可靠 📰 新闻（8-20）

类型开发者工具 / AI
核心事实v1.0 将 HTTP 层从 httpx 迁移至 httpx2（社区维护的 API 兼容 fork），要求 Python 3.10+；同时下线老的 Text Completions API、移除 temperature/top_p/top_k 参数；保留 DefaultHttpxClient 助手用法，调用方可在启动时通过 httpx2.alias_httpx() 适配仍以 httpx 为追踪目标的库。

背景Anthropic 把 SDK 推到 v1.0 是把 HTTP 层与新版 Claude API 行为对齐；temperature/top_p/top_k 在新版 Sonnet/Opus 4.x 与 Mythos 路线上逐步无效，Anthropic 选在 SDK 层一刀切。
各方反应海外开发者社区主要在评估 httpx2 的兼容窗口，常见问题是 mock / tracing 库所 patch 的 httpx 是否需要切换。
