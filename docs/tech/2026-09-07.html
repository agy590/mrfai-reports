4. Google Gemini API 文档更新：流式 TTS + 图像模型弃用清单

核心事实：在 gemini-3.1-flash-tts-preview 模型上，streamGenerateContent（含 Interactions API stream: true）现支持 TTS 流式输出；同时明确部分旧图像生成模型将于 2026-08-17 停服。

5. Google I/O 2026：Gemini 3.5 Flash 已 GA，Pro 进入月度滚动

核心事实：5 月 I/O 公布 Gemini 3.5 Flash 即时可用，Pro 在次月滚动；官方称 Flash 输出 tokens/秒 为前沿模型的 4×。

为什么重要：Flash / Pro 双线策略意味着 Google 在成本侧有强对位武器；Pro 的滚动节奏影响企业迁移时点。

今日观察

  • "computer-use" 已成旗舰模型的新基线：Astra 把"驱动桌面 / 填表 / 操作 CRM / 前端 QA"做成主卖点；Fable 5.1 的 Mythos 也在 cybersecurity / life sciences 上强调 agentic。这意味着 2026 下半年的 frontier 模型叙事，正在从"更长上下文 / 更高 IQ"切换到"能自己动手做事"。
  • 价格战往下打到 cache 层：Anthropic 把 cache-read 直接降 75%，这是把"长会话成本"打到不可逆的低价位。开发者层面对话历史、RAG 检索缓存会更激进地写入。
  • Agent 工具栈进入"harness"军备：GitHub 日榜首的 ECC 显示，围绕 Claude Code / Codex / Cursor 的"代理框架 / 习惯 / 记忆层"已是真实产品类别——不再是单点 prompt 优化，而是系统工程。
  • 平台层兼容风险：Astra 锁定在"高网络与关键基础设施安全阈值"，意味着 GPT-6 完整能力对一般开发者并非完全开放；Mythos 5.1 同样走 trusted access。这对构建在"开放 API 假设"上的初创公司是一道提醒。
