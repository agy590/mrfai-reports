1. 阿里开源 Qwen-Image-2.1：7B 单流 DiT + 原生 RGBA + 10 参考图编辑

科技 / 开源模型 ⭐ 高热 📰 新闻 🟢 多方确认

核心事实：2026-09-20 通义千问在 qwen.ai 官方博客发布 Qwen-Image-2.1，视觉生成组件 32 层 Single-Stream DiT / 7B 参数，文本与视觉编码器为 Qwen3-VL 8B，64 通道 RGBA VAE / 16× 空间压缩；统一文生图与图像编辑、原生透明通道、最多 10 张参考图、局部编辑（圆形 / 笔刷 / mask）；权重开源至 GitHub、Hugging Face、ModelScope；vLLM-Omni Day-0 支持，含 FP8 量化、CUDA Graph decode、TP/Ulysses 并行；研究 license + 商业部署需另签。

关键数据
7B 视觉参数 / 32 层 DiT / 10 参考图 / RGBA 输出 / FP8 量化
背景
2025-12 通义曾发布独立模型 Qwen-Image-Layered 专门做透明生成；本次合并为单一模型是工作流整合尝试。
各方反应
官方（qwen.ai 博客）：定位为 "compact, efficient, and unified image creation"；
开源社区（GitHub / Comfy-Org）：Day-0 提供 ComfyUI 工作流；
第三方分析（buildfastwithai / explainx / runtimewire）：肯定透明度 + 编辑能力；指出商业部署仍需单独 license。
影响分析
短期——设计 / 电商 / 短剧道具资产自动化场景门槛降低。中期——商业 license 摩擦决定企业采用速度，是与"完全 Apache 开放"路线（如 FLUX）的关键差异。
