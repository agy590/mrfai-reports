别让 Agent 替你做决定

2026-10-12 · AI Agent

把判断权交给 Agent，是这一行最容易踩、也最不该踩的坑。

我自己最早栽过的一个跟头：让 Agent 顺手帮我"决定下一步该做什么"。结果是它确实很勤快——列任务、拆步骤、跑命令、汇报结果；但每一步都在一个我自己没明说的假设上滑行。我以为它在替我想清楚，它以为我在授权它直接推进。两边都对，但加在一起就是把判断悄悄外包了。

后来我给自己立了一个死规矩：Agent 可以提议、可以执行、可以替我查资料；判断、批准、和"这件事到底要不要做"，必须留在人这边。不是因为 Agent 笨，而是因为一旦把判断也交出去，你就再也不知道它替你跳过了哪一步。

具体怎么做

  1. 先写一句话目标。任何任务开始前，自己用一行中文写清楚"今天要交付的是什么"；写不出来的，先别启动 Agent。
  2. 区分"建议"和"动作"。Agent 输出方案时，标清楚"这是建议，需要你点头"；要执行的动作单列一栏，等你逐条确认。
  3. 强制一个冷却点。涉及发布、付费、删改、对外发消息这四类动作，Agent 就算做完了也只给摘要，最后那一下"提交"必须你自己按。
  4. 事后写一句复盘。跑完一个回合，花两分钟记一句"哪一步是 Agent 替我决定的，我原本不一定同意"；连续记一周，你会看见自己的盲区。

本文为个人经验与观点，不构成投资或技术建议。文中提到的工具与方法仅作示例，请按自身情况审慎评估。
