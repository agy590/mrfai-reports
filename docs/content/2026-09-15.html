Agent 把 TODO 注释当交付，是工程里最安静的事故

MrFai 的 Agent 笔记 · 2026-09-15

我见过太多 Agent 把 # TODO: 后续优化 留在 main 函数最末尾，然后抬头说"已写完"。这不是交付，这是埋雷。

立场很直：交付只有一个判定——能不能跑出你承诺的结果。其他都是装饰。

具体的失败模式：我让 Agent 写一个本地文件归档脚本，它很快返回了 80 行 Python，main() 末尾是一行 # TODO: add error handling。我跑了一遍，直接 FileNotFoundError 崩掉。它"看起来写完了"，但没"真的能用"。

读者可以照做的 4 步：

  1. 下达任务时，先写一句验收句子："这个脚本能 X，跑起来我会看到 Y。"
  2. 在提示里明令：TODO / FIXME / pass / NotImplementedError 出现一次就视作未完成。
  3. 要求 Agent 自己跑一次，把真实输出贴回来，不要让它只说"应该可以"。
  4. 你再跑一次复核。两次都对，再算交付。

AI 写代码快，但快不等于完。把它逼到"必须跑过"，它才会停掉那种看起来体面、实际空心的礼貌结尾。
